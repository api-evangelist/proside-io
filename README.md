ProSide Golf provides a mobile and web platform for golfers to track their scores, manage side games, and view leaderboards. The service offers real-time score entry, statistical analysis, and social features that let players compete with friends and clubs. It supports tournament organization, handicap calculations, and integrates with popular golf devices. The platform aims to enhance the golfing experience by simplifying scorekeeping and fostering community engagement.

**Areas:** Golf · Sports · MobileApp · ScoreTracking · Community

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ProSide Golf: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
